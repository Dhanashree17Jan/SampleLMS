Schoolnet / Training Management

Create a batch.
Bring a plan to life.

Choose a published training plan, set the batch dates, assign trainees, and schedule delivery. This guide follows the current Schoolnet application.

Open Batches in the sidebar, then select + Create batch. The local application form is at localhost:5080/Batches/Edit.

01 Before you begin

The right access

Administrators and coordinators can create batches. A coordinator can manage batches only within assigned projects. Trainers and trainees cannot create batches.

Ready to select

You need an active project, an active school linked to that project, and an existing Published training plan. Draft and Archived plans cannot be selected for a new batch.

Before scheduling

Have an active trainer and at least one eligible active trainee ready. You can save the draft first and assign these before scheduling.

02 Create and schedule

Step through the workflow. Click a step, use Back / Next, or focus the walkthrough and press the arrow keys.

Step 1 / Open form

Sign in as an administrator or coordinator. Open Batches and select + Create batch. Enter a unique batch code and a descriptive batch name.

Step 2 / Choose context

Select an active project you can manage, then an active school linked to that project. The project and school determine which trainees are eligible for the roster.

Step 3 / Plan and dates

Select a Published plan using its name, version, and duration. Choose the start date. Number of days comes from the plan; end date is calculated automatically. Choose an active trainer now, or add one before scheduling.

Step 4 / Save draft

Select Save draft batch. The batch detail page opens with the selected plan and dated daily activities. Saving the draft does not schedule it. Use Edit draft to adjust setup while permitted.

Step 5 / Assign eligible trainees

On the detail page, select trainees under Assign eligible trainees, then choose Assign selected trainees. Each trainee must be active and match the batch project and school. Duplicates and conflicting scheduled training dates are rejected. Each assignment starts with Not marked attendance for every plan day.

Step 6 / Schedule batch

Review dates, plan, trainer, and roster. Under Batch lifecycle, select Schedule batch. Eligibility and overlaps are checked again. Setup and roster lock after scheduling. A batch whose start date has arrived shows In progress.

04 Explore batch dates

This example uses a four-day plan. Change the start date to see the batch calendar move. It is a demonstration and does not save anything to Schoolnet.

Calculated end date

Inclusive calendar days

End date = start date + number of days − 1
Day date = start date + day number − 1

Dates follow consecutive calendar days, including weekends. In the application, changing duration requires selecting another Published plan.

05 Shared plan, separate records

A plan describes numbered activities. Each batch gives those activities its own calendar dates and trainee assignments.

What is shared

The selected Published plan version, its duration, and its numbered activity content. Creating a batch does not copy or alter the plan.

What belongs to the batch

Project, school, trainer, dates, roster, attendance, and feedback. With 20 trainees and a four-day plan, the batch starts with 80 Not marked attendance entries.

06 Checks and next steps

If this happensWhat to check
No plan is availableAsk an administrator to publish a complete plan, then reload the form.
School is unavailable or rejectedCheck that the school and project are active, linked, and accessible to you.
No eligible trainees appearCheck active trainee profiles against the selected project and school. Trainees already assigned to this batch do not appear in the selection list.
Trainee assignment is rejectedCheck project/school eligibility, duplicate selection, and overlapping Scheduled or In progress training dates.
Scheduling is rejectedConfirm the batch is Draft, the plan remains Published, an active trainer is selected, and at least one eligible trainee is assigned.
You need to change scheduled setupReturn to Draft only before the start date, with no marked attendance or submitted feedback. Otherwise the setup stays locked.
After scheduling

Mark attendance only for available batch days; future-date attendance is blocked. Day 1 uses the Pre form and Day N uses Feedback. Feedback submission never marks attendance.

Complete the batch after its end date once all attendance is marked. Missing feedback does not block completion. Cancellation requires a reason and preserves training history.
